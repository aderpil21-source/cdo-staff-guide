# Интерактивная инструкция ЦДО

Служебное руководство для сотрудников Центра дополнительного образования Западного филиала РАНХиГС.

**Актуальная версия:** v3.2  
**Опубликованная инструкция:** https://aderpil21-source.github.io/cdo-staff-guide/

## Публикация

Сайт автоматически публикуется через GitHub Pages после обновления `guide.zip` в ветке `main`.

В репозитории нет паролей, PIN-кодов, токенов или иных секретов. Служебные данные передаются сотрудникам отдельно.

Основной сайт ЦДО находится в отдельном репозитории и этим репозиторием не изменяется.
